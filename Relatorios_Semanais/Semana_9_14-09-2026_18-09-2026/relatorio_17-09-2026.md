## Hoje, pesquisei uma forma de configurar containers do Docker de maneira remota, encontrando várias maneiras: a variável DOCKER_HOST, a copia manual dos ficheiros através de um servidor SSH e comandos no cmd, e a utilização de Docker Contexts, que são uma especie de aliases para as distintas conexões remotas no nosso computador. Após gerar uma key SSH no computador local e enviar para o computador remoto, conseguimos executar comandos nele desde o computador local. Com o comando "docker context create nome --docker "host=(nossohost)"", conseguimos verificar os containers disponíveis no computador remoto e executar comandos importantes como docker compose up -d, mas adicionando os parámetros --context nome ao comando (o comando ficaria "docker compose --context nome up").
