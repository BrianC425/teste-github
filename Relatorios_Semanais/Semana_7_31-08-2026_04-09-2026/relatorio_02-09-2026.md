## Hoje, dia 02/09/2026, explorei a maneira mais fácil de ter dois agentes a funcionar, um gerando código e o outro verificando esse código antes da sua execução.

### Uma boa forma de ter dois agentes a funcionar, com o segundo (B) verificando o que o primeiro (A) vai executar antes de ser executado, seria indicar ao agente A que gere o código que precisamos executar e que faça também um export do mesmo de maneira organizada a um ficheiro JSON (ou qualquer outra extensão). O ficheiro, para além do código a executar, teria o reasoning do agente para gerar esse código. Depois, no segundo agente, pediríamos para ler o ficheiro gerado e também para executar o mesmo em caso de não houver nenhum erro. Caso houver erro, o agente B pode indicar a solução a o/os problema/as num novo ficheiro, o qual iriamos devolver ao agente A para gerar o código novamente com os cambios. O agente A envia de novo o código e o reasoning para o ficheiro JSON, sobreescrevendo o ficheiro anterior, o que permite ao agente B verificar novamente para encontrar novos erros ou executar.
### É possível automatizar o processo inteiro utilizando ferramentas como LangGraph, que permite definir módulos que executam uma ação automaticamente. Neste caso, sería necessário definir o módulo do agente A, que verifica o feedback do agente B (ou não, se for a primeira vez que o código é gerado) e gera o código com base ao input do usuário, o módulo do agente B que verifica o código gerado pelo agente A e devolve feedback detalhado, e o módulo do agente B que executa o código caso o feedback seja positivo. Desta forma, só interatuamos com a IA uma vez, no principio, e o LangGraph utiliza os módulos criados para automatizar o resto do processo.
